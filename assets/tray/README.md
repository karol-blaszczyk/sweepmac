# sweepmac tray icon v3

This is the recommended status icon: a compact **geometric broom plus one sparkle**. The symbol uses a single-color alpha template and is designed specifically for 18 pt macOS menu-bar display, with matching 1x, 2x, and 3x PNG assets plus an SVG master.

Use the black template PNG (or SVG) in native template mode. macOS will apply the appropriate light or dark status-bar tint. The white assets are only previews/fallbacks for a tray path without template tinting.
